EXPERIMENT BLUEPRINT / GENERATED LOCALLY

From construct design to interpretation.

Use the sequence as a staged plan. Earlier gates prevent a folding defect from being mislabeled as mechanism.

A / PERTURBATION LADDER
Change chemistry in interpretable steps.
  1. Conservative—Tests whether subtle side-chain chemistry matters.
  2. Neutralizing—Reduces the dominant chemical feature.
  3. Structural stress test—Use only after the gentler construct is interpretable.
B / MEASUREMENT GATES
Measure in this order.
  1. Gate 0

    Confirm numbering, construct sequence and assay dynamic range.

  2. Gate 1

    Check abundance plus one folding or stability readout.

  3. Gate 2

    Measure the protein-specific functional output.

  4. Gate 3

    Compare candidate, matched residue and wild type in the same batch.

C / RESULT INTERPRETER
What the pattern would mean.
Function changes; integrity holds

Structural hypothesis survives the first specificity gate.

Function and integrity both fall

Treat as a stability or expression explanation first.

Candidate equals comparison

The site is not more informative than structural background.

No measurable effect

Move to the next-ranked residue or improve assay sensitivity.

D / COMPETING EXPLANATIONS
Keep these alive until the data separate them.
  • Local packing change rather than a specific functional pathway.
  • Expression, trafficking or folding loss rather than site-specific biology.
  • The supplied static state may not represent the assay-relevant conformation.
NEXT SITE IF INCONCLUSIVE—
