What this analysis adds

From a structure to a controlled residue test.

A structure viewer shows coordinates. RINet adds a reproducible ranking, a matched lower-score control, the contribution of each score term, cutoff sensitivity, mutation chemistry, and criteria for interpreting the experiment. It complements PyMOL, ChimeraX, evolutionary analysis and simulation.

INPUTStructure

One coordinate model with author chain IDs, residue numbering, ligands, missing atoms and quality fields.

METHODRanking

Ten residues, a matched lower-score control, and explicit weights for every score term.

OUTPUTExperiment

Candidate and control mutations, integrity checks, a functional readout and a stopping rule.

LIMITStructure-derived evidence

Energy, dynamics, evolution and causal biology require separate data.

EXPERIMENT PLAN

Build, measure, compare, interpret.

Start with the lowest-risk perturbation. Check expression and folding before interpreting function.

A / MUTATION SERIES
Test one chemical property at a time.
  1. First property probePendingUses the least severe interpretable change available; “conservative” is not assumed.
  2. Property-removing probePendingRemoves or reduces the dominant chemical feature.
  3. Network-pair controlPendingTests the linked structural explanation after the first construct is interpretable.
B / MEASUREMENT GATES
Measure in this order.
  1. Gate 0

    Confirm numbering, construct sequence and assay dynamic range.

  2. Gate 1

    Check abundance plus one folding or stability readout.

  3. Gate 2

    Measure the protein-specific functional output.

  4. Gate 3

    Compare candidate, matched residue and wild type in the same batch.

C / RESULT TABLE
Interpret the four common outcomes.
Function changes; integrity holds

Structural hypothesis survives the first specificity gate.

Function and integrity both fall

Treat as a stability or expression explanation first.

Candidate equals comparison

The site is not more informative than structural background.

No measurable effect

Move to the next-ranked residue or improve assay sensitivity.

D / ALTERNATIVE EXPLANATIONS
Test these before assigning mechanism.
  • Local packing change rather than a specific functional pathway.
  • Expression, trafficking or folding loss rather than site-specific biology.
  • The supplied static state may not represent the assay-relevant conformation.

Interpretation limits

Read before ordering constructs

Static coordinates

No dynamics, kinetics, conformational ensemble or energetic coupling is inferred from one model.

Residue-level graph

Cα contacts are a coarse structural description, not an all-atom potential, folding model or free-energy calculation.

Biological assembly

The supplied coordinate file may contain an asymmetric unit, crystal contacts or an incomplete biological assembly.

Numbering and construct

Author numbering, insertion codes, unresolved residues, tags and assay constructs must be reconciled experimentally.

Evolution absent by default

Conservation is not invented. Use the FASTA/BLAST route or import external evidence before making evolutionary claims.

Validation scope

Known-site recovery and cutoff stability support inspection; they do not establish general predictive performance.
