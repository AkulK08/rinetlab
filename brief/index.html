How the residue ranking and comparison mutation are calculated

Every proposed mutation is ranked for the same user-chosen functional site. Its comparison residue has similar local chemistry and structure but a lower predicted effect on that site. Run both mutations to test whether the higher-ranked residue really gives a more specific result.

01Define the target

Use a ligand pocket, biological interface, or experimentally established residue set.

02Solve the response

Apply balanced forces to the target and solve the anisotropic elastic network along three axes.

03Check robustness

Repeat at 8.0, 8.5 and 9.0 Å so a fragile network cutoff does not silently drive the result.

04Change local constraints

Choose a substitution that removes or alters side-chain contacts without automatically choosing the most destructive mutation.

05Run the comparison

Test a structurally similar mutation predicted to affect the chosen site less. If both mutations behave alike, the ranking did not isolate a specific residue effect.

DISTANCE FROM FUNCTIONAL SITE—Range of distances covered by the proposed mutations.
RANKING STABILITY—Average stability of the proposed mutations across the three network cutoffs.
MEAN PREDICTED-EFFECT REDUCTION—How much lower the comparison mutations rank for predicted effect on the chosen site.
COMPARISON MUTATIONS—Structurally similar residues predicted to affect the chosen site less.
SCIENTIFIC BASISEstablished mechanics; a new experiment-design integration
Anisotropic Network Model ↗

A Cα elastic network provides the directional Hessian used for near-native collective response.

Perturbation-response scanning ↗

Linear response to residue forces has been used to connect structural perturbations with observed conformational change.

ENM parameter analysis ↗

The 8.5 Å primary cutoff and the three-cutoff check follow published evaluation of elastic-network parameterization.

Dynamic Coupling Index ↗

Normalizing a site's response by background compliance is established; RINet extends the idea to a selected target-region cross-compliance contrast.

Allosteric-site benchmark ↗

Energy-weighted bond-propensity methods show why predicted long-range effects should be benchmarked against known allosteric systems.

RINET TARGETED MECHANOCHEMICAL CONTRAST

RINet links the calculation to the lab decision: choose a functional site; calculate which residues should affect it; check whether the ranking survives three network cutoffs; choose a mutation from observed local contacts; find a structurally similar comparison mutation; collect function, abundance and fold/assembly; then choose the next construct from the result. Prospective performance must still be established on held-out systems.

C / WHAT THE RESULT MEANS
Four common outcomes
Function changes; quality holds

Repeat the result, then test a stronger mutation at the same residue.

Function and quality both fall

Treat as a stability, expression, or assembly defect first.

Both mutations behave alike

Do not prioritize this residue; test the next-ranked residue or revise the assay.

No measurable effect

Check assay sensitivity, then build the next-ranked mutation.

Interpretation limits

Read before ordering constructs

Coarse-grained mechanics

The elastic response is a linear, near-native-state calculation from one conformation. Compare relevant states or use MD when anharmonic motion, kinetics, solvent, membranes, or large rearrangements matter.

Mechanical response is not ΔΔG

The anisotropic network estimates target-to-residue compliance. Mutation relaxation, atomistic energetics and binding or folding free energy require a separate validated calculation or experiment.

Biological assembly

The supplied coordinate file may contain an asymmetric unit, crystal contacts or an incomplete biological assembly.

Numbering and construct

Author numbering, insertion codes, unresolved residues, tags and assay constructs must be reconciled experimentally.

Evolution absent by default

Conservation is not invented. Use the FASTA/BLAST route or import external evidence before making evolutionary claims.

Validation scope

Known-site recovery and cutoff stability support inspection; they do not establish general predictive performance.
