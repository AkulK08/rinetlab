02–03 / CANDIDATE + CONTROL

Run high-sensitivity mutations beside low-sensitivity controls.

Each pair is matched on residue chemistry and local structural environment but separated by its predicted effect on compliance of the same functional target. This makes the mechanical calculation experimentally falsifiable. Probable disulfides are excluded because breaking a covalent bond would confound the comparison.

Why this is a mechanistic experiment rather than a list of important residues

Every candidate is tied to the same user-chosen functional target. The high-sensitivity mutation and its low-sensitivity control are matched locally, so their difference tests the compliance calculation instead of merely asking whether a highly connected residue is important.

01Define the target

Use a ligand pocket, biological interface, or experimentally established residue set.

02Solve the response

Apply balanced forces to the target and solve the anisotropic elastic network along three axes.

03Check robustness

Repeat at 8.0, 8.5 and 9.0 Å so a fragile network cutoff does not silently drive the result.

04Change local constraints

Choose a substitution that removes or alters side-chain contacts without automatically choosing the most destructive mutation.

05Challenge the model

Run a locally matched mutation with weak target-compliance sensitivity. Similar outcomes count against the mechanical explanation.

Anisotropic Network Model ↗

A Cα elastic network provides the directional Hessian used for near-native collective response.

Perturbation-response scanning ↗

Linear response to residue forces has been used to connect structural perturbations with observed conformational change.

ENM parameter analysis ↗

The 8.5 Å primary cutoff and explicit cutoff sensitivity follow published evaluation of elastic-network parameterization.

Dynamic Coupling Index ↗

Normalizing a site's response by background compliance is established; RINet extends the idea to a selected target-region cross-compliance contrast.

Allosteric-site benchmark ↗

Energy-weighted bond-propensity methods show why target-directed propagation should be benchmarked against known allosteric systems.

RINET TARGETED MECHANOCHEMICAL CONTRAST

The implemented contribution is the full lab decision: choose a functional target; compute first-order target-compliance sensitivity and cutoff robustness; select a mutation from explicit local constraints; generate a locally matched low-sensitivity control; collect function, abundance and fold/assembly; then choose the next construct from the paired outcome. Prospective performance must still be established on held-out systems.

Method scope

What RINet calculates

RINet turns a known functional site into a testable perturbation experiment. It builds a directional Cα elastic network, solves the target-loaded response, calculates how weakening springs around each residue changes target compliance to first order, checks the result at three cutoffs, audits what a substitution changes locally, and selects a locally matched low-sensitivity control.

INPUTStructure

Author chain IDs, residue numbering, ligands, missing atoms and quality fields remain visible.

CALCULATIONTarget → mechanical response

Directional elastic response, normalized cross-compliance, cutoff robustness, and mutation-specific local constraints.

EXPERIMENT OUTPUTCandidate + control

Mutation set, protein-quality measurements, functional readout, and interpretation rule.

MODEL REGIMENear-native linear mechanics

Use atomistic energy, ensembles or MD as a separate layer when relaxation, solvent, kinetics or large state changes determine the question.

Interpretation limits

Read before ordering constructs

Coarse-grained mechanics

The elastic response is a linear, near-native-state calculation from one conformation. Compare relevant states or use MD when anharmonic motion, kinetics, solvent, membranes, or large rearrangements matter.

Mechanical response is not ΔΔG

The anisotropic network estimates target-to-residue compliance. Mutation relaxation, atomistic energetics and binding or folding free energy require a separate validated calculation or experiment.

Biological assembly

The supplied coordinate file may contain an asymmetric unit, crystal contacts or an incomplete biological assembly.

Numbering and construct

Author numbering, insertion codes, unresolved residues, tags and assay constructs must be reconciled experimentally.

Evolution absent by default

Conservation is not invented. Use the FASTA/BLAST route or import external evidence before making evolutionary claims.

Validation scope

Known-site recovery and cutoff stability support inspection; they do not establish general predictive performance.
