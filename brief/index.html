ROUND 1 · PANEL DESIGN

First-round constructs

The panel includes wild type, structurally distinct candidate sites, and lower-scoring controls matched on residue class, burial, B-factor field, and chain. Residues assigned probable disulfide bonds remain visible in the audit but are excluded from automatic panels.

PANEL COVERAGE—Mean coverage of the top 120 residues in normalized ten-feature space.
RANK-ONLY COVERAGE—The same calculation using the top N residues without panel design.
MODEL-SEPARATION INDEX—Scaled minimum distance between the five expected readout patterns; not an accuracy estimate.
PAIRED CONTROLS—Lower-scoring structural matches included with the candidates.
WORKING MODELS USED FOR PANEL SELECTION

Each model maps the displayed structural features to expected changes in function, abundance, and fold/assembly. Panel contrasts use expected function change minus the mean expected protein-quality change. These patterns are design assumptions, not fitted predictions.

01Long-range connectivity

Function follows long-range contacts, closeness, or betweenness while protein quality is retained.

02Direct local contact

Function follows ligand, metal, interface, or local-contact geometry.

03Protein-quality loss

Functional change is accompanied by lower abundance or disrupted fold/assembly.

04Packing density

Response follows contact degree, weighted packing, and burial.

05Combined features

No single structural feature group dominates the expected response.

Method scope

What RINet calculates

From one coordinate model, RINet builds a Cα contact graph, calculates the displayed residue scores, selects lower-scoring structural controls, and repeats the ranking at 7, 8, and 9 Å cutoffs. PyMOL and ChimeraX remain the appropriate tools for general structure inspection.

INPUTStructure

Author chain IDs, residue numbering, ligands, missing atoms and quality fields remain visible.

CALCULATIONRank and compare

Ten residues, every weighted term, and a matched lower-score control.

EXPERIMENT OUTPUTCandidate + control

Mutation set, protein-quality measurements, functional readout, and interpretation rule.

NOT CALCULATEDAdditional evidence

Evolution, dynamics, energetics, cellular phenotype, and causal mechanism require separate analyses.

Ranking checks

Sensitivity and reference checks

Known residues are applied after scoring. The panels report reference-site recovery, contact-cutoff sensitivity, and an optional second-structure comparison.

A / KNOWN-SITE RECOVERY

B / CONTACT-CUTOFF SENSITIVITY

Rank stability across 7–9 Å

Large rank changes indicate dependence on the contact definition and should be reported with the result.

C / SECOND CONFORMATION

Compare the same protein in another state

No second state loaded. RINet will compare matched chain/residue identifiers, contact changes and rank shifts.
D / SCOPE OF THIS CHECK

Reference check, not general validation

The built-in known sites test whether the ranking recovers established structural anchors in selected examples. It is not a substitute for blinded multi-protein benchmarking against mutational, allosteric, evolutionary or MD datasets.

C / RESULT CLASSIFICATION
Four common outcomes
Function changes; quality holds

Candidate has a function-specific effect relative to the control.

Function and quality both fall

Treat as a stability, expression, or assembly defect first.

Candidate equals control

The experiment does not distinguish the selected site from structural background.

No measurable effect

Check assay sensitivity, then test the next site.

D / ALTERNATIVE EXPLANATIONS
Potential confounders
  • Local packing change rather than a specific functional pathway.
  • Expression, trafficking or folding loss rather than site-specific biology.
  • The supplied static state may not represent the assay-relevant conformation.

Interpretation limits

Read before ordering constructs

Static coordinates

No dynamics, kinetics, conformational ensemble or energetic coupling is inferred from one model.

Residue-level graph

Cα contacts are a coarse structural description, not an all-atom potential, folding model or free-energy calculation.

Biological assembly

The supplied coordinate file may contain an asymmetric unit, crystal contacts or an incomplete biological assembly.

Numbering and construct

Author numbering, insertion codes, unresolved residues, tags and assay constructs must be reconciled experimentally.

Evolution absent by default

Conservation is not invented. Use the FASTA/BLAST route or import external evidence before making evolutionary claims.

Validation scope

Known-site recovery and cutoff stability support inspection; they do not establish general predictive performance.
