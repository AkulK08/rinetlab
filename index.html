01 / Flagship facilities

Three laboratories.
One structural question.

Most tools end at a ranked residue list. RINet asks whether that list survives alternative states, uncertainty partitions, contact definitions and matched controls—and keeps every intermediate claim inspectable.

A / STATE ATLAS

See which structural differences actually persist.

Map, superpose and compare a supplied state library while retaining missing-residue masks and contact changes. Structural display similarity is explicitly not TM-score or lDDT.

  • PAIRWISE RMSD + CLUSTERING
  • CONTACT GAINS AND LOSSES
  • RIGID-COMMUNITY MOTION
  • 2–32 SUPPLIED STATES
B / CONSENSUS DOMAIN LAB

Separate stable domain boundaries from PAE artifacts.

Compute multi-scale partitions for each exact model/PAE pair, then expose co-assignment, ARI stability, interface evidence and abstention instead of forcing a clean answer.

  • FULL PAE DIMENSIONALITY GATE
  • MULTI-SCALE SPECTRAL PARTITIONS
  • CO-ASSIGNMENT + ARI STABILITY
  • EXPLICIT ABSTENTION
C / ALLOSTERIC CONSENSUS

Stress-test a pathway before spending the plate.

Rebuild the graph across radii, atom definitions, confidence weighting and supplied states. Compare multiple centralities with degree-preserving nulls and matched negative controls.

  • CA + HEAVY-ATOM GRAPH FAMILIES
  • FIVE CENTRALITY DEFINITIONS
  • DEGREE-PRESERVING NULLS
  • FALSIFYING EXPERIMENTS

05 / Scientific scope

Useful because it refuses to pretend.

Not AlphaFold inference

RINet analyzes supplied structures and uncertainty data. It does not predict a fold from sequence or reproduce AlphaFold neural inference.

Not causal proof

Allosteric consensus is hypothesis-generating network evidence. A robust graph signal still requires experimental validation.

Not a trajectory

Interpolated structural views are mathematical display aids, not molecular dynamics or a claim about physical kinetics.

Not one score

State, uncertainty and graph evidence remain separately inspectable so disagreement cannot be hidden by aggregation.
